# Offline Lens

화면이나 사진 속 한국어 지문·영수증을 읽고 질문에 답하는 **오프라인 macOS 앱**입니다. 영수증의 구매 수량·무게·개당 가격과 기초 계산, 한국어 지문 질문을 처리합니다.

**화면 캡처·사진 → Apple Vision OCR → 영수증 표 복원·검산 → 로컬 AI 답변** 순서로 동작합니다. AI는 이미지에서 추출한 텍스트를 읽습니다. 최초 설치 후에는 인터넷이나 외부 API 없이 사용할 수 있습니다.

## 스펙

| 항목 | 내용 |
|---|---|
| 환경 | Apple Silicon Mac, macOS 13 이상 |
| 구현 | Swift 5.9 이상 · AppKit · Apple Vision OCR |
| 선택 모델 | Qwen2.5 7B Instruct · Q4_K_M |
| 모델 용량 | GGUF 2개, 합계 약 4.68GB — 메모리 사용량과는 별개 |
| 추론 런타임 | llama.cpp `b11284` |
| 추론 설정 | CPU 전용, 추론·입력 처리 각 2스레드, 컨텍스트 2,048토큰, 출력 최대 256토큰 |
| AI 입력 제한 | 지문 1,600자 · 질문 200자 |
| AI 실행 제한 | 최대 60초, 중지 가능, 작업 완료 후 모델 프로세스 종료 |
| 데이터 처리 | 지문·답변은 저장하지 않으며 캡처 임시 파일은 OCR 후 삭제 |

## 실행

Apple Command Line Tools와 Python 3가 필요합니다. 개발 도구가 없다면 `xcode-select --install`로 설치하세요.

```sh
git clone https://github.com/93TEI/offline-lens.git
cd offline-lens

# 최초 1회: 모델과 런타임 다운로드 — 인터넷 필요
python3 scripts/install-local-ai.py --model qwen2.5-7b-q4

# 모델을 포함한 앱 빌드 및 실행
sh scripts/build.sh
open 'dist/Offline Lens.app'
```

이후에는 `dist/Offline Lens.app`을 열어 사용합니다. 모델·런타임은 Git 저장소에 포함되지 않습니다. 모델 설치를 생략하면 OCR와 지원되는 규칙 계산만 사용할 수 있습니다.

## 사용법

1. 읽을 화면을 띄우고 **메뉴 막대 카메라 아이콘**을 누르거나, 앱에서 **사진 열기**로 이미지를 선택합니다. 캡처는 마우스가 있는 모니터에 보이는 화면 전체를 한 번 찍습니다. 앱이 활성화되어 있으면 `⌘⇧S`도 사용할 수 있습니다.
2. 추출한 글자·영수증 표와 자동 입력된 질문을 확인하고 필요하면 수정합니다.
3. **풀이하기**를 누릅니다. 모델이 설치되어 있으면 로컬 AI가 기본으로 켜집니다. **로컬 AI로 풀이**를 끄면 지원되는 계산을 규칙으로 처리합니다.
4. 추론 중에는 **AI 중지**를 누를 수 있으며, 창을 닫으면 앱이 종료됩니다.

첫 캡처 때 **시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음**에서 Offline Lens를 허용해 주세요. 사진 열기에는 이 권한이 필요하지 않습니다. OCR와 AI 답변은 원본과 대조하고, 표를 복원하지 못한 영수증은 품목·수량·금액을 수정한 뒤 풀이하세요.
